YoableSeg - Grounded-SAM-2 Implementation with SAM3
====================================================

IMPLEMENTATION SUMMARY
----------------------
This project now implements the exact pipeline from IDEA-Research's Grounded-SAM-2 
repository, but using SAM3 instead of SAM2 as requested.

Repository Reference: https://github.com/IDEA-Research/Grounded-SAM-2


KEY CHANGES MADE
----------------

1. INFERENCE PIPELINE (inference_server.py)
   
   Following Grounded-SAM-2 exact workflow:
   
   Step 1: Grounding DINO Detection
   - Text prompts → bounding boxes
   - Returns: boxes (xyxy format), scores, labels
   - Uses: IDEA-Research/grounding-dino-base
   
   Step 2: Non-Maximum Suppression (NMS)
   - Remove duplicate/overlapping detections
   - IoU threshold: 0.5
   - Keeps highest confidence boxes
   
   Step 3: SAM3 Batch Inference
   - Input: boxes from Grounding DINO
   - Output: precise segmentation masks
   - Uses: facebook/sam3 (instead of SAM2)
   - FP16 inference on GPU for speed
   
   Step 4: Post-Processing
   - Remove small regions (min_area=100 pixels)
   - Fill holes (morphological closing, kernel=7)
   - Resolve overlaps (higher score wins)
   
   Step 5: Polygon Conversion
   - Binary mask → contour detection
   - Polygon simplification
   - YOLO segmentation format output


2. UPDATED run_grounding_dino() METHOD
   
   Changed from returning list of tuples to:
   - Returns: (boxes_np, scores_list, labels_list)
   - Matches Grounded-SAM-2 pattern
   - Better numpy array handling


3. UPDATED autolabel() ENDPOINT
   
   Implements exact Grounded-SAM-2 logic:

TECHNICAL DETAILS
-----------------

Pipeline Comparison:

Grounded-SAM-2 (Original):
  Input → Grounding DINO → NMS → SAM2 → Post-process → Output

YoableSeg (This Implementation):
  Input → Grounding DINO → NMS → SAM3 → Post-process → Output
          (same base)              ^^^
                                (only difference)


Models Used:
- Grounding DINO Base: IDEA-Research/grounding-dino-base
  (Same as Grounded-SAM-2 HuggingFace version)
  
- SAM3: facebook/sam3
  (Replacing SAM2 from original implementation)


Key Differences from Original Grounded-SAM-2:
1. Uses SAM3 instead of SAM2 (as requested)
2. Uses HuggingFace Transformers for both models
3. No local checkpoint files needed
4. Same algorithmic pipeline
5. Same post-processing utilities


Post-Processing Pipeline:
1. remove_small_regions() - removes disconnected small blobs
2. fill_holes() - morphological closing + contour hierarchy
3. resolve_overlaps() - assigns pixels to highest-scoring mask
4. mask_to_polygon() - contour detection + simplification

INSTALLATION
------------
Run: YoableSeg/PythonService/install.ps1

This will:
1. Create Python virtual environment
2. Install PyTorch with CUDA 12.1
3. Install dependencies
4. Download SAM3 model (~3.5GB)
5. Download Grounding DINO Base (~933MB)
6. Setup HuggingFace authentication
